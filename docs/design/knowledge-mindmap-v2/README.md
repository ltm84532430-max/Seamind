## 从现有界面修正什么

1. **固定软件结构**：60 px 全局导航、258 px 内容树、58 px 顶栏；知识库和导图共享外框，但各自保留专属工作区。顶部只承载工作区切换和全局搜索，不堆编辑命令。
2. **明确任务入口**：知识库首页把“继续阅读”放在最大区域，分类和模板靠右，文档数、导图数和分类数只占一行。内容用真实的标题、类型、位置、最近编辑时间构成列表，不用装饰性大卡片代替文件管理。
3. **阅读优先**：文档分栏内每篇文章有独立标题、路径、阅读/编辑切换及滚动区。页面级工具只负责分栏、跨内容查看和分享。正文行宽、字号、行距与表格密度按长文阅读处理。
4. **画布优先**：导图浏览态把大部分窗口交给节点和连线，只展示根、一级和少量二级节点；节点数量是文档元信息，不要求一次把 64 个节点缩到看不清。缩放、适配画布和大纲切换固定在底部。
5. **编辑聚焦**：只有进入编辑态，才显示 Markdown 源码和节点详情。左侧 310 px 源码区、右侧 272 px 详情区；选中节点与源码行同步高亮。内容、样式、关系分成详情页签；备注、附件、图片、代码与关联文档各有明确位置。
6. **生态感来自统一语言**：低饱和植物绿贯穿导航、选中态、连线和主按钮；纸白内容面与淡绿色背景区分阅读和管理；橘色与蓝色只表达次要分支或内容类型。用细线、留白和一致的圆角建立层次，避免重阴影和过量渐变。

## 组件和尺寸

| 区域 | 设计规格 | 约束 |
| --- | --- | --- |
| 全局导航 | 60 px 宽，图标按钮 40 × 40 px | 始终可见，活动工作区有色块反馈 |
| 内容树 | 258 px 宽，搜索框 32 px 高，树项 33 px 高 | 分类层级最多两级直接展示；长标题截断 |
| 顶栏 | 58 px 高 | 全局搜索与个人入口；不放节点操作 |
| 页面工具栏 | 54 px 高 | 面包屑、保存状态和页面级动作 |
| 导图页标题栏 | 66 px 高 | 导图名、节点数、浏览/编辑、样式、导出 |
| 文档分栏 | 主区 52% / 48% | 每个文档各有自己的阅读滚动区 |
| 导图编辑 | 源码 310 px / 画布弹性 / 详情 272 px | 画布空间不足时应折叠非焦点侧栏 |
| 字体层级 | 页面题 29 px，文章题 29 px，导图题 17 px，正文 13.2 px | 辅助文字最低约 10.5 px，正式实现需核查缩放与系统字体 |
| 色彩 | 主色 `#466D59`，正文 `#1D2C24`，边线 `#E2E7DF` | 状态不只靠颜色表达 |

## 页面级交互

- 知识库列表行打开对应文档；树中选择分类过滤列表。搜索覆盖标题、路径和标签，输入期间反馈范围和结果数。
- 同一文档可在多个标签中打开。单页、左右、上下分栏是布局选项；正文滚动和阅读/编辑模式属于各窗格，互不干扰。
- 导图浏览时，单击选中并显示内容摘要，双击展开或收起分支；“适应画布”按可见节点计算，不能把隐藏分支计入边界。
- 导图编辑时，选中节点定位 Markdown 行；在源码里定位标题也应选中节点。详情区的标题、备注与附件修改后呈现保存状态。
- HTML 导出保留在导图的页面级主操作；导出设置和完成反馈需清楚说明范围与输出文件位置，导出的离线阅读界面与桌面编辑界面分开设计。

## 对现有实现的落点

- `KnowledgeWorkspace.tsx`：对照首页、分类树、标签和多分栏文档状态，先整理页面结构与组件边界，再替换样式。
- `App.tsx`：对照顶部工作区切换、导图标题和导图工具栏；将浏览与编辑的控件显隐按状态梳理。
- 导图画布与节点卡片：需要以可读缩放为目标，保存/恢复视角仍按现有行为；图像、表格、代码、备注卡片应保持当前内容能力。
- 当前四张图是设计规格，尚未进入生产前端，也不代表功能已实现。实施时逐项验证键盘操作、窄窗口、深色主题、空状态以及现有 Markdown/HTML 导出行为。
