# 电子书试卷与间隔复习

试卷页位于顶部“试卷”入口。电子书阅读器负责按章节生成试卷；试卷页负责检索、作答、查看成绩与复习队列。书架上每本书的“试卷”按钮会直接筛选到该书。在线找书仍从书架进入。

## 排程规则

- 首次交卷后安排次日复习。连续达到掌握标准的交卷轮次，建议间隔依次为 1、3、7、14、30、60 天；60 天为当前上限。
- 掌握标准是最近一轮整卷作答质量不低于 80%。逐题计算：有自评与评分时取两者平均；只有一种时使用该结果；未评价的题目记 0。再除以整卷题数，避免只答对少数题便延长复习间隔。自评“掌握 / 部分掌握 / 待复习”分别记为 1 / 0.5 / 0。全卷无评分也无自评时按未达标处理，并保持 1 天间隔。
- 重新作答但尚未交卷时，上一轮交卷时间与复习进度保留；如果已到复习日，逾期和今日提醒继续显示。提交新一轮后再重新计算日期。
- 到期按本机日历日判断；逾期、今日、三日内和作答中的数量直接出现在试卷页，逾期与今日到期的合计显示在顶部入口。页面每分钟和窗口重新可见时更新紧迫性。
- 曲线仅展示建议间隔，**不是个人记忆率或学习效果的测量**。用户的作答和自评会调整后续间隔，具体天数是产品规则，允许后续用真实学习数据校准。

间隔练习和主动提取的依据可参见 [Cepeda 等人的间隔实验](https://laplab.ucsd.edu/articles/Cepeda%20et%20al%202008_psychsci.pdf) 与 [Karpicke、Roediger 的提取练习实验](https://doi.org/10.1126/science.1152408)。两项研究支持分散练习与重复提取，但并未证明上述固定的 1/3/7/14/30/60 天适合每个学习者。

## 实现位置

- 前端入口与队列：`apps/desktop/src/exams/ExamCenterWorkspace.tsx`、`review-schedule.ts`、`exam-center.css`。
- 试卷作答与生成：`apps/desktop/src/exams/EpubExamWorkspace.tsx`、`epub-exam-generation.ts`，阅读器入口在 `src/ebook/EpubReader.tsx`。
- 后端试卷存储和摘要：`apps/desktop/src-tauri/src/exams/epub_exam.rs`。摘要提供最近交卷时间、连续掌握轮次和最近作答质量，沿用现有试卷文件，不迁移用户数据。
