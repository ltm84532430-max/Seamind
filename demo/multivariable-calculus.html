02 / Derivative

方向导数 Dᵤf—
∇f = (∂f/∂x, ∂f/∂y)

z切 ≈ f₀ + fₓ(x−x₀) + fᵧ(y−y₀)
直观理解

05 / The Idea

从一元导数到多元导数

一元函数的导数是曲线上一点的切线斜率。二元函数的图像是一张曲面；固定 y 得到 x 截面，固定 x 得到 y 截面，分别求得偏导数。两条截面的坡度组成梯度，线性近似则给出曲面在该点附近的切平面。 

// 每次拖动滑块，SVG 都按当前参数重算
fx = 0.6 * x0
fy = 0.9 * y0
gradient = (fx, fy)
directionalDerivative = fx * cos(theta) + fy * sin(theta)
tangentPlane = f0 + fx * (x - x0) + fy * (y - y0)

// 二重积分的中点近似
volume ≈ Σ f(xᵢ*, yⱼ*) · Δx · Δy
